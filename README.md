# Радужная деревня — Minecraft Forge 1.8.9

Мод добавляет семь вариантов радужного кирпича, кристалл призмы, Радужное огниво и отдельное измерение с небольшой спектральной деревней.

## Сборка

Требуется JDK 8 и Gradle. Выполните `gradle setupDecompWorkspace` (один раз), затем `gradle build`. Готовый JAR появится в `build/libs/`.

## Игровые механики

- Радужные кирпичи: красный, оранжевый, жёлтый, зелёный, голубой, синий и фиолетовый. Текстура каменного кирпича окрашена; одинаковые соседние блоки выглядят насыщеннее, а полная последовательность семи цветов в ряд слегка мерцает.
- Рецепт кирпичей: 4 каменных кирпича и соответствующий краситель (бесформенный крафт).
- Кристалл призмы: стекло + светокамень + любой краситель.
- Радужное огниво: железный слиток + огненный стержень + фиолетовый краситель.
- Постройте в одной плоскости прямоугольную рамку 3×4 из радужных кирпичей, оставив середину пустой. Поставьте Кристалл призмы в проём, на один блок выше нижнего ряда рамки. Используйте по нему Радужное огниво. Обычное огниво портал не активирует.
- После активации игрок переносится в измерение Радужной деревни; деревня строится при первом посещении. Выход — повторное использование активированного кристалла.
