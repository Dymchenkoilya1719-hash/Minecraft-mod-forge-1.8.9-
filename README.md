# Радужная деревня — Minecraft Forge 1.8.9

Мод добавляет семь вариантов радужного кирпича, Кристалл призмы, Радужное огниво и отдельное измерение с небольшой спектральной деревней.

## Сборка

Требуется JDK 8. Выполните `gradle setupDecompWorkspace`, затем `gradle build`. Готовый JAR появится в `build/libs/`.

## Игровые механики

- Радужные кирпичи: красный, оранжевый, жёлтый, зелёный, голубой, синий и фиолетовый. Текстура каменного кирпича окрашивается; соседние блоки того же цвета выглядят насыщеннее, а линия из семи цветов слегка мерцает.
- Кирпич: бесформенный рецепт из четырёх каменных кирпичей и соответствующего красителя.
- Кристалл призмы: стекло, светокамень и любой краситель.
- Радужное огниво: железный слиток, огненный стержень и фиолетовый краситель.
- Постройте прямоугольную рамку 3×4 из радужных кирпичей и поставьте Кристалл призмы в её проём. Используйте на кристалле Радужное огниво; обычное огниво не активирует переход.
- Переход ведёт в отдельное измерение Радужной деревни; небольшое поселение создаётся при первом посещении.
