# Радужная деревня (Forge 1.8.9)

Семь вариантов радужного кирпича, кристалл-призма с проверкой арки, Радужное огниво и отдельное измерение с небольшой спектральной деревней.

## Сборка

Требуются JDK 8 и совместимая с ForgeGradle 2.1 версия Gradle (рекомендуется Gradle 2.14.1). Выполните:

```sh
gradle setupDecompWorkspace
gradle build
```

JAR появится в `build/libs/`. Новые версии Gradle не гарантируют совместимость с ForgeGradle 2.1.

## Рецепты и использование

- Радужный кирпич: четыре каменных кирпича и соответствующий краситель; рецепт бесформенный. Цвета: красный, оранжевый, жёлтый, зелёный, голубой, синий и фиолетовый.
- Кристалл призмы: стекло, светокамень и любой краситель.
- Радужное огниво: железный слиток, огненный стержень и фиолетовый краситель.
- Постройте вертикальную рамку 3×4 из кирпичей: полный периметр, углы обязательны, середина свободна. Плоскость рамки может быть направлена по X или Z. Установите кристалл в нижнюю центральную ячейку проёма; верхняя центральная ячейка должна оставаться свободной.
- Щёлкните Радужным огнивом по кристаллу. Сервер проверит рамку, запустит короткую анимацию частиц и перенесёт игрока в измерение Радужной деревни. Используйте Радужное огниво в деревне, чтобы вернуться в обычный мир. Обычное огниво портал не активирует.

Мод использует текстуры Minecraft 1.8.9 (`stonebrick`, `glass`, `flint_and_steel`) и JSON-модели из ресурсов мода; окраска кирпичей применяется tint-обработчиками.
